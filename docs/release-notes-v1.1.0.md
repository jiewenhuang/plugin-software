# 软件中心 v1.1.0

本版本新增可选的 Halo MCP Server 集成，AI 客户端可通过访问密钥管理软件、版本、下载源、分类、标签和专题。未安装 MCP Server 时，软件中心可独立运行。

## 新增能力

- 34 个基础工具：14 个查询工具、20 个创建/更新/发布/删除工具。
- 2 个默认关闭的下载敏感配置工具，读取和写入可分别授权；普通工具的读写结果始终隐藏敏感值。
- 查询支持明确的业务筛选、排序和分页；默认每页 20 条，最多 100 条。
- 更新使用 `expectedVersion` 防止覆盖并发修改，支持局部 patch 和明确的 `clearFields`；省略字段保留原值。
- 软件与专题默认创建为草稿，发布状态通过独立工具修改；版本默认 draft，下载源默认禁用。
- 继续使用现有引用、slug、版本唯一性、下载目标和删除约束校验。
- 增加输入/结果大小边界、超时错误与成功写入的大结果回执；不自动重试冲突和不确定的写入。

完整工具目录、参数和错误契约见 [MCP 接入文档](../dev/mcp.md)。设计背景见 [实现方案](mcp-integration-plan.md)。

## 兼容性与安装

- **最低 Halo 版本由 2.25.0 提升至 2.26.0。** Java 构建版本保持 21。
- 可选 MCP Server 依赖范围为 `>=1.0.0 & <2.0.0`；实际编译和联调版本为 **1.0.0**。
- MCP API 使用 compileOnly，不随软件中心 JAR 打包；不引入第二个 MCP 服务。
- AI Foundation 仍为可选依赖；基础 MCP 工具不依赖它。
- 不更改现有 Extension GVK，不引入业务数据迁移，不改变 Console 的原有替换/合并 API 契约。

将构建得到的 `plugin-software-1.1.0.jar` 上传到 Halo Console，安装兼容的 MCP Server 后，在「工具 → MCP 服务」中为密钥勾选需要的 `software__` 工具。已有密钥不会自动获得新增工具。

## 使用边界

- 管理查询包含草稿。MCP 密钥按工具白名单授权，不继承普通 Console 用户的角色配置。
- 单次 Handler 预算为 4 秒。写入超时返回 `WRITE_OUTCOME_UNKNOWN`，必须先查询实际状态再决定是否重试；不提供持久化创建幂等键。
- 不提供同步 AI 建议工具。客户端可以生成内容后调用普通写入；站点 AI Foundation 的异步作业不在本版本范围内。
- 关闭 MCP 开关、撤销密钥或停用 MCP Server 可以关闭入口，不会回滚已经完成的数据修改。
- MCP Server 的最近调用记录为内存记录，不属于持久化审计。

本地构建和验证已完成；此说明不表示已经创建 GitHub Release 或部署到生产站点。
